BC-DCT : Band Controlled DCT Model. 
Used for creating data for testing. (Low band is preserved, Mid band is sloghtly amplified and High band is amplified the most.

DP-GAN : Direct-Perturbation GAN
Used for create training data. Only Spatial features were fed to generator. generator learn perturbation and clips on the image. 

FA-GAN : Frequency-Aware GAN
Used for create training data. Both Spatial and Frequency patterns are fed to the generator. The generator learns both perturbation and clips on the image.
